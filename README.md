# soc-n1-Caso-23-TalentoRemoto

# SOC Nivel 1: Caso C23 - TalentoRemoto Staffing TI S.A.S.

Repositorio técnico correspondiente al caso de estudio de implementación de seguridad defensiva, monitoreo de eventos, protección de endpoints y gestión de incidentes de seguridad informática.

## 🚀 Componentes del Proyecto

- **Monitoreo y SIEM (Wazuh):** Instalación y registro del agente en Ubuntu, monitoreo de eventos de seguridad, configuración de FIM (Monitoreo de Integridad de Archivos), SCA (Evaluación de Configuración de Seguridad), detección de vulnerabilidades y reglas personalizadas de alertas.
- **Protección de Endpoints (Kaspersky EDR Cloud):** Administración de dispositivos, despliegue de agentes de seguridad, configuración de políticas, análisis de amenazas y gestión de alertas de seguridad.
- **Mesa de Ayuda y Gestión de Incidentes (GLPI):** Organización de tickets, documentación de incidentes, seguimiento de alertas y registro de acciones de respuesta.
- **Análisis de Incidentes:** Investigación de eventos sospechosos, clasificación por severidad, recopilación de evidencias y documentación de procedimientos de respuesta.

## 🛠️ Tecnologías Utilizadas

- **Wazuh** — SIEM y monitoreo de seguridad.
- **Kaspersky EDR Cloud** — Protección y administración de endpoints.
- **GLPI** — Gestión de servicios de TI y tickets de incidentes.
- **Ubuntu Linux** — Sistema operativo del agente de monitoreo.
- **Windows** — Entorno de administración y pruebas.
- **Oracle VirtualBox** — Plataforma de virtualización del laboratorio.
- **GitHub** — Control de versiones y documentación técnica.

## 📂 Estructura del Repositorio

- `evidencias/` — Capturas de pantalla y resultados de la práctica.
- `informes/` — Informes técnicos y análisis de incidentes.
- `scripts/` — Scripts utilizados durante la configuración y el monitoreo.
- `README.md` — Documentación general del proyecto.

## 🎯 Objetivo

Implementar y documentar un entorno de seguridad defensiva SOC Nivel 1 para el caso C23 TalentoRemoto, integrando herramientas de monitoreo, protección de endpoints y gestión de incidentes, con el propósito de identificar, analizar y documentar eventos de seguridad informática.
